Ask the user a question and wait for the answer; the turn pauses until it
arrives. Optionally offer choices as multiple-choice options.

Use it only when the task is genuinely ambiguous in a way the repository
cannot resolve, when the next step is destructive or hard to reverse, or when
the workspace contradicts your brief. Ask precisely: state the options you see
and say which you would pick and why. Do not use it for progress updates —
your final message is the report — and never use it to ask for plan approval,
which is propose_plan's job. Asking twice about the same thing means the
question was too thin; sharpen it.
