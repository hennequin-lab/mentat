Declare or advance the session goal — the long-horizon objective that persists
across turns and drives continuation until it is complete, paused, or blocked.
Actions: declare, pause, resume, edit, clear, complete, block; declare and
edit carry the objective text, and an optional token_budget caps the spend
before the goal pauses for the user to resume.

A goal outlives a single turn, unlike the task board (todo_write), which
tracks the steps within the current stretch of work. Declare a goal for a
multi-turn effort the user wants carried to completion; use the board for the
steps inside it. Mark the goal complete only when its requirements genuinely
hold — verified, not assumed.
