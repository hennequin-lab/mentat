Send additional context to a running child session without starting a new
turn: steer it mid-run, add a constraint, or answer a question it asked you.
Delivery is immediate and never blocks; a running child sees the message
before its next step. To start a fresh turn on a child that has gone idle, use
follow_up instead. A child's context stays intact, so prefer messaging an
existing child over spawning and re-briefing a new one.
